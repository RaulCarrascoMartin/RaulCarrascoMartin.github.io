Proyecto principal

Biblioteca

Java · Spring Boot

Aplicación web de gestión de biblioteca — catálogo, préstamos/devoluciones y usuarios con roles — construida como monolito modular: cuatro módulos de negocio (libro, usuario, prestamo, auth) con fronteras explícitas y arquitectura por capas interna, verificadas automáticamente en cada build.

  • 106 tests (87 de integración/unitarios + 19 reglas de arquitectura con ArchUnit) sobre H2 en modo MySQL.
  • Autenticación JWT en cookie HttpOnly con doble mecanismo de revocación: lista de denegación para logout puntual y tokenVersion por usuario para invalidar todas las sesiones.
  • Bloqueo pesimista en préstamos para evitar condiciones de carrera en peticiones concurrentes sobre el mismo libro.
  • README de más de 500 líneas documentando cada decisión de arquitectura, sus compromisos y limitaciones conocidas.
Java 21 · Spring Boot 4.1 · Spring Security · JPA · MySQL / H2 · JWT · ArchUnit Ver repositorio

BetterFishingApp

Swift · SwiftUI

App de pesca para iOS: identifica la especie capturada por foto usando reconocimiento visual (API de Fishial.ai) y guarda la captura con los datos pre-rellenados.

  • Arquitectura feature-first con MVVM; dependencias unidireccionales Features → Services → Core.
  • Servicios externos tras interfaces ("seams") para poder inyectar dobles en tests — XCTest unit + UI.
  • Gestión de estados de carga, reintento y niveles de confianza en la identificación.
Swift 5.9 · SwiftUI · iOS 17+ · URLSession · Supabase Ver repositorio
02

p4g_saveConverter

Python

Conversor de partidas guardadas de Persona 4 Golden (PC → PS Vita): reimplementación propia del formato binario del save, documentada con el proceso de ingeniería inversa que llevó a encontrarla.

  • Corrige un bug del conversor original (partidas en español congelaban el juego) mediante prueba sistemática de variantes del formato.
  • Conserva slots existentes en destino, valida tamaños y recalcula checksums antes de escribir.
  • Sin dependencias externas; funciona con el Python preinstalado en macOS.
Python 3 · ingeniería inversa de formato binario Ver repositorio
03

tboi_saveConverter

Python

Downgrade de guardados de The Binding of Isaac: Repentance+ a Repentance 1.7.9b, para usarlos en un port no oficial a PS Vita.

  • Valida cabecera y checksum (CRC) del binario antes y después de transformarlo.
  • Modo conservador: si el formato no es el esperado, no escribe nada; crea copia de seguridad automática si el destino ya existe.
Python 3 · validación binaria y CRC Ver repositorio
